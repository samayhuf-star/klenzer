### StoreKit 2 (item 6) breakdown

- **RevenueCat removed:** no `react-native-purchases` / RevenueCat / `appl_` / `EXPO_PUBLIC_RC` / `klenzer_pro` in `package.json`, `package-lock.json` (0 hits vs 4 for `expo-iap`), `eas.json`, `app.json` plugins, or src imports. `expo-iap` `^6.4.3` is a dependency and an `app.json` plugin. Purchases import `expo-iap` (`purchases.ts:24`).
- **Three products, loaded by ID** (`src/lib/products.ts:17–38`): `com.krosz.klenzer.yearly` (subs, default, “BEST VALUE”), `com.krosz.klenzer.monthly` (subs), `com.krosz.klenzer.lifetime` (in-app). Loaded via `fetchProducts({ skus, type })` (`purchases.ts:163–176`). **No hardcoded prices in src.** The intended store prices ($19.99 yearly, $3.99 monthly, $29.99 lifetime) are not in the app; the UI shows `product.displayPrice` (`purchases.ts:179, 186`; `paywall.tsx` plan price). Yearly may be missing in ASC on the first TestFlight pass (fix notes).
- **Verified + `finishTransaction`:** `verifyOnDevice` uses `isTransactionVerifiedIOS` / `currentEntitlementIOS` (`purchases.ts:63–76`); then `finishTransaction({ purchase, isConsumable: false })` (`:108`).
- **Entitlement:** Pro if a verified lifetime purchase **or** an active yearly/monthly (`refreshEntitlements`, `hasActiveSubscriptions` / `getActiveSubscriptions` + `s.isActive`, `:195–226`). Expired subs should not stay Pro. Checked at boot (`initIAP` then `refreshEntitlements` before `setReady`, `store.tsx:116–118`) and on transaction updates.
- **Restore:** `syncIOS` + `restorePurchases`; Settings and paywall have Restore (`purchases.ts` `restore()`; `settings.tsx:51`; paywall still has the link).
- **Error state:** if none load, paywall shows **“Plans unavailable right now, try again later”** and Try again (`purchases.ts:160–161, 188–190`; `paywall.tsx:100–106`). Partial loads are shown (yearly can be absent).
